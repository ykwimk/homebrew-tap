# ykwimk/homebrew-tap

Homebrew casks for [Agent Overtime](https://github.com/ykwimk/agent-overtime), a macOS app that shows your Claude Code sessions in a pixel office.

```
brew install --cask ykwimk/tap/agent-overtime
```

The app is not notarized by Apple, so the first launch needs **System Settings > Privacy & Security > Open Anyway**. Then follow [the app's README](https://github.com/ykwimk/agent-overtime#readme) to connect Claude Code.

Each cask pins the release `.dmg` by its SHA-256, the same value listed in the release notes.

Bugs and questions go to the [Agent Overtime repository](https://github.com/ykwimk/agent-overtime/issues).
